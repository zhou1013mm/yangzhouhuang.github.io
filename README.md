
This is my personal blog site repo forked from [Minimal Mistakes Jekyll theme](https://mmistakes.github.io/minimal-mistakes/).

The site should be editted in the `\test\` directory. If you want to move the site outside of the `\test\` folder, you can pay attention to the original repo and documentation. Some path and url configurations in the `Rakefile`, `.gitignore`, `\test\_config.yml` and `\_data\navigation.yml` should be your primary interest when editting.
